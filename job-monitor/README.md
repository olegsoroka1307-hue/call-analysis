# Монітор замовлень на Freelancehunt

Кожні N хвилин перевіряє нові замовлення, відсіює чуже, а на підхоже
надсилає вам у Telegram картку із **готовою чернеткою відгуку**.

Навіщо саме так: на біржах виграє не найдешевший, а той, хто відповів
першим. Відгуки в перші 30 хвилин після публікації читають майже всі
замовники, через три години — майже ніхто. Монітор перетворює ці 30 хвилин
із випадковості на правило.

**Він нічого не подає за вас.** Тільки знаходить, оцінює і готує текст —
відгук ви надсилаєте самі, поглянувши на нього. Масові автовідгуки псують
репутацію на біржі швидше, ніж приносять замовлення.

---

## Подивіться, як воно працює

Без ключів, без акаунтів, без інтернету — на вигаданій стрічці:

```bash
cd job-monitor
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python tools/demo_run.py
```

Побачите сім замовлень: які пройдуть, які відсіються і чому, і які
чернетки вийдуть.

---

## Що потрібно від вас

### 1. Токен Freelancehunt (2 хвилини)

Зайдіть у свій акаунт на Freelancehunt → розділ **«Додатки та API»** →
створіть персональний токен. Покладіть його у файл `.env` поряд із `run.py`:

```
FREELANCEHUNT_TOKEN=ваш-токен
```

Це офіційне API біржі, а не парсинг сторінок — нічого не порушується.

### 2. Опишіть, що ви продаєте (10 хвилин — найважливіше)

Скопіюйте `config.example.yaml` у `config.yaml` і перепишіть поле
`my_offer`: послуги, назви пакетів, ціни, терміни і — обовʼязково —
**чого ви не робите**. Останнє не менш важливе: саме за ним модель
розпізнає чужі замовлення й попереджає вас, замість того щоб писати
впевнений відгук на роботу, якої ви не виконуєте.

### 3. Ключ Anthropic — за бажанням

Потрібен лише для чернеток відгуків, приблизно **1 цент за чернетку**.
Без нього запускайте з ключем `--no-draft`: монітор і далі знаходитиме
замовлення, просто без готового тексту.

```
ANTHROPIC_API_KEY=sk-ant-...
```

### 4. Сповіщення в Telegram — за бажанням

1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → отримаєте токен →
   у `.env`: `TELEGRAM_BOT_TOKEN=...`
2. Напишіть своєму боту `/start` — без цього Telegram не дасть йому вам писати
3. Дізнайтесь свій chat_id: відкрийте
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` — число в полі
   `"chat":{"id":...}` і є він
4. У `config.yaml`: `notify_telegram: true` і `telegram_chat_id: "ваш-id"`

**Не надсилайте нікому** вміст `.env`, токен Freelancehunt і токен бота.
Для допомоги з налаштуванням достатньо тексту помилки з екрана.

## Запуск

```bash
./.venv/bin/python run.py                # один прогін
./.venv/bin/python run.py --every 15     # перевіряти кожні 15 хвилин
./.venv/bin/python run.py --no-draft     # без чернеток, без витрат на ШІ
```

Щоб працювало саме́, у фоні — рядок у `crontab -e`:

```
*/15 * * * * cd /шлях/до/job-monitor && ./.venv/bin/python run.py >> data/cron.log 2>&1
```

## Як налаштувати відсів під себе

Усе в `config.yaml`, кодом чіпати нічого не треба.

| Симптом | Що змінити |
|---|---|
| Забагато сміття | Підніміть `min_score` (7 → 9) |
| Мало замовлень, пропускаєте своє | Знизьте `min_score` (6 → 4) |
| Приходить дизайн і копірайтинг | Допишіть слова у `stop_words` |
| Приходить те, за що не беретесь | Опишіть це в `my_offer`, розділ «не роблю» |
| Дорого виходять чернетки | Підніміть `draft_min_score` — чернетки лише для найкращих |
| Приходить із запізненням | Знизьте `max_bids` (25 → 10) |

**Як рахуються бали.** Кожна група слів у `keywords` має вагу. Збіг у групі
додає її вагу, кожне наступне слово тієї ж групи додає ще по балу — тому
одне влучне слово важить майже стільки ж, скільки п'ять випадкових згадок.
Слова зі `stop_words` віднімають по 4.

Замовлення без указаного бюджету **не відсіюються**: на біржах його часто
не вказують, а домовляються в переписці.

## Як читати картку

```
🎯 Назва замовлення
💰 бюджет · скільки вже відгуків · коли опубліковано
📊 релевантність · яку саме вашу послугу пропонувати
🔑 слова, за якими воно знайшлось
посилання

─── ЧЕРНЕТКА ВІДГУКУ ───
перше речення · пакет · ціна · питання

⚠️ Для вас, не в відгук: застереження
```

Останній рядок — найважливіший. Він зʼявляється, коли модель бачить
розбіжність: замовник просить платформу, якої немає у вашій пропозиції,
або задача взагалі не ваша. **Читайте його до того, як надсилати відгук.**

Перше речення чернетки навмисно починається з ситуації замовника, а не з
вас. Відгуки, що починаються з «Доброго дня, готовий виконати вашу задачу»,
не дочитують — це найчастіша причина, чому фрилансер відгукується
тридцять разів без результату.

## Чого монітор не робить

- не подає відгуки й не пише замовникам — тільки вам
- не парсить сторінки біржі: працює через офіційне API
- не показує одне замовлення двічі
- не зникає мовчки: якщо канал сповіщень упав, замовлення лишається
  непоказаним і прийде наступного разу

По **Useme** такого монітора немає: у них не знайшлося ні публічного API,
ні RSS. Там або вручну, або через браузер.

## Для розробника

```bash
./.venv/bin/python -m pytest        # 57 тестів, мережа не потрібна
./.venv/bin/python tools/demo_run.py
```

Контракт API (`monitor/freelancehunt.py`) звірено з офіційною клієнтською
бібліотекою `freelancehunt-api` з PyPI: база `https://api.freelancehunt.com/v2`,
заголовок `Authorization: Bearer`, ендпоінт `/projects`, фільтри
`filter[skill_id]` і `page[number]`, відповідь у форматі JSON:API.
