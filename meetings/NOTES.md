# Нотатки по інтеграції з Notion

## База «Домовленості»

- data source id: `7ad757f3-3042-45ff-acc2-df0979dd6326`
- поля: Задача (title), Відповідальний, Дедлайн (date), Пріоритет (select),
  Статус (select), Проєкт (multi_select), Джерело, Цитата

## Знахідки, які треба врахувати в `notion.py`

**1. Значення select і multi_select мають існувати заздалегідь.**
Notion відхиляє запис із помилкою `validation_error`, якщо в полі «Проєкт»
приходить назва, якої немає серед опцій:

```
Invalid multi_select value for property "Проєкт": "Продажі".
Value must be one of the following: .
```

Це не дрібниця: модель щоразу вигадує назву проєкту з контексту наради, і
рано чи пізно назве щось нове. У клієнта це впало б посеред розбору.

Рішення в коді: перед записом читаємо схему бази, і якщо потрібної опції
немає — або додаємо її через `PATCH /v1/databases/{id}`, або пишемо задачу
без поля «Проєкт» і фіксуємо це в журналі. Мовчки втрачати задачу не можна.

Те саме стосується «Пріоритету» і «Статусу», тільки там набір закритий і
задається нами, тому достатньо звірки на боці коду.

**2. Дата передається окремим полем `start`.**
Не рядком у «Дедлайн», а структурою `{"date": {"start": "2026-08-21"}}`.

**3. Права інтеграції.**
Самого токена мало. Інтеграції потрібні `Read content`, `Insert content` і
`Update content`, і базу треба явно додати у вкладці **Content access** —
інакше API відповідає «сторінку не знайдено», хоча токен правильний.
