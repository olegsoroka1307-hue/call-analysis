# Тріаж вхідної пошти

Система читає вашу пошту, розуміє, що в ній написано, і кожні пів години кладе
вам у таблицю короткий звіт: що важливе, що ні, а що варто подивитися особисто.

**Вона вміє лише читати.** Видалити, надіслати чи переслати листа вона не може —
не тому, що їй заборонено, а тому, що доступ, який вона просить у Google,
такої можливості не містить.

---

## Що ви отримуєте

Для кожного листа — рядок у таблиці:

| Вердикт | Що це означає |
|---|---|
| 🔴 **IMPORTANT** | Треба ваша увага. Поруч — хто написав, про що, що зробити і до якої дати |
| ⚪ **NOT_IMPORTANT** | Розсилка, автоматичне сповіщення, реклама. Дій не потребує |
| 🟡 **NEEDS_HUMAN_REVIEW** | Система не впевнена. Подивіться самі |

Третій вердикт — не збій, а сенс системи. Помилково позначити важливий лист
неважливим коштує дорожче, ніж зайвий раз вас потурбувати. Тому в сумнівних
випадках система завжди обирає вас.

---

## Спершу подивіться, як воно працює

Це можна зробити **прямо зараз**, не даючи системі жодного доступу — ні до
пошти, ні до платного API. Прогін іде на вигаданих листах:

```bash
cd email-triage
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python tools/demo_run.py
```

Ви побачите сім листів і рішення по кожному, зокрема лист із PDF-рахунком,
неоднозначний лист і лист, у якому зловмисник намагається обдурити систему.

---

## Що потрібно від вас

Три речі. Двох із них не може зробити ніхто, крім власника акаунтів.

### 1. Ключ до ШІ (5 хвилин)

**Що зробити.** Зайдіть на `console.anthropic.com`, поповніть баланс,
розділ **API Keys** → **Create Key**. Скопіюйте ключ.

**Навіщо.** Це те, чим оплачується робота ШІ. Орієнтовно **2–3 центи за лист**
(докладний розрахунок — у `ARCHITECTURE.md`).

**Куди покласти.** Створіть поряд із `run.py` файл `.env` із одним рядком:

```
ANTHROPIC_API_KEY=sk-ant-ваш-ключ
```

### 2. Доступ до Gmail (15 хвилин, один раз)

**Навіщо.** Без цього система не побачить листів.

**Куди натискати:**

1. `console.cloud.google.com` → створіть проєкт (назва будь-яка)
2. **APIs & Services → Library** → знайдіть **Gmail API** → **Enable**
   *(якщо звіт буде в Google Таблиці — увімкніть ще й **Google Sheets API**)*
3. **APIs & Services → OAuth consent screen** → тип **External** → заповніть
   назву й свою пошту → у розділі **Test users** додайте свою адресу
4. **APIs & Services → Credentials** → **Create credentials** →
   **OAuth client ID** → тип **Desktop app**
5. Натисніть **Download JSON**. Покладіть файл у папку `secrets/`
   під іменем `credentials.json`
6. Виконайте: `./.venv/bin/python run.py --auth` — відкриється браузер,
   підтвердіть доступ

> **Важливо про 7 днів.** Поки застосунок у статусі *Testing*, Google відкликає
> доступ кожні 7 днів, і крок 6 доведеться повторювати. Щоб цього не було,
> на екрані **OAuth consent screen** натисніть **Publish app**. Для застосунку,
> яким користуєтесь тільки ви, перевірка Google не потрібна.

### 3. Опишіть свій бізнес (10 хвилин — найважливіший крок)

Скопіюйте `config.example.yaml` у `config.yaml` і перепишіть поле
`business_context` **своїми словами**: чим ви займаєтесь, які листи для вас
важливі, які ні, а які підозрілі.

Це не формальність. Саме за цим текстом ШІ вирішує долю кожного листа.
«Важливо: клієнти» дасть посередній результат. Речення на кшталт
«Важливо: будь-що від Іванова з ТОВ Альфа, вони зараз судяться з нами»
дасть точний.

## 🔒 Чого НЕ можна надсилати виконавцю

Навіть якщо він попросить. Ці речі не потрібні для роботи ніколи:

| Не надсилати | Чому |
|---|---|
| Пароль від Gmail чи Google-акаунта | Система працює через окремий доступ, пароль їй не потрібен взагалі |
| Коди з SMS, підтвердження входу | Це доступ до всього вашого акаунта |
| Файли `secrets/credentials.json` і `secrets/token.json` | Це ключі до вашої пошти. Вони мають лишатись тільки на вашій машині |
| Ваш ключ `ANTHROPIC_API_KEY` | Ним оплачується робота з вашого балансу |
| Архів або вивантаження всієї пошти | Для налаштування досить 2–3 листів як прикладів |

**Що надіслати можна й треба:** 2–3 приклади типових листів (за потреби
зафарбуйте прізвища й суми), текст помилки з екрана, вміст `config.yaml`
(секретів у ньому немає за задумом).

Якщо виконавець наполягає на чомусь із лівої колонки — це привід зупинитися.

## Щоденне користування

```bash
./.venv/bin/python run.py
```

Система візьме нові листи, обробить і допише рядки у звіт. Двічі один лист
не обробляється. Наприкінці ви побачите підсумок і скільки листів чекають
на ваш перегляд.

**Щоб запускалося саме́,** щопівгодини, на Linux або Mac:

```bash
crontab -e
# додайте рядок (підставте свій шлях):
*/30 * * * * cd /шлях/до/email-triage && ./.venv/bin/python run.py >> data/cron.log 2>&1
```

## Як читати звіт

Дивіться згори вниз, колонка **Вердикт**:

- **IMPORTANT** — читайте колонки «Що зробити» і «Дедлайн». Це ваш список справ.
- **NEEDS_HUMAN_REVIEW** — колонка «Чому такий вердикт» пояснює, що збентежило систему.
- **Підозра на маніпуляцію = «так»** — у листі є текст, що намагався обдурити
  класифікатор. Такі листи відкривайте обережно: це майже завжди шахрайство.
- **Знижена якість = «так»** — вердикт поставила не модель, а захисне правило
  (збій API або спрацював фільтр). Такому рядку довіряйте менше.

## Коли щось не працює

| Що на екрані | Що робити |
|---|---|
| `Проблема з налаштуваннями` | Текст помилки називає конкретне поле в `config.yaml` |
| `Не заданий ANTHROPIC_API_KEY` | Немає файлу `.env` або в ньому одруківка |
| `Немає файлу secrets/credentials.json` | Не пройдено крок 2 |
| Просить увійти в Google щотижня | Не натиснуто **Publish app** — див. врізку про 7 днів |
| Забагато листів у NEEDS_HUMAN_REVIEW | Опишіть бізнес докладніше в `business_context`, або знизьте `confidence_threshold` до 0.6 |
| Важливе потрапляє в NOT_IMPORTANT | Підніміть `confidence_threshold` до 0.85 і допишіть у `business_context`, що саме пропустили |
| Рахунок за ШІ більший, ніж хотілося | Увімкніть `skip_bulk_mail: true` — розсилки перестануть іти в модель |

Усі помилки пишуться у файл `data/errors.jsonl` із часом і причиною.

---

## Чого система не робить

Свідомо, за задумом, а не через незавершеність:

- не видаляє й не архівує листи
- не відповідає й не пересилає
- не позначає листи прочитаними
- не передає вміст вашої пошти нікуди, крім API Anthropic для класифікації
- не приймає рішень замість вас — вона лише сортує й підсумовує
